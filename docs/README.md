# Tài liệu dự án

Thư mục tài liệu cho `java-engineering-patterns`.

## Mục lục

- [`pattern-catalog.md`](pattern-catalog.md) — **Mục lục liên kết tới README của mọi pattern.**
- [`architecture.md`](architecture.md) — Kiến trúc hệ thống, module chính, luồng dữ liệu.
- [`development.md`](development.md) — Thiết lập môi trường, cài dependency, lệnh build/test.
- [`onboarding.md`](onboarding.md) — Hướng dẫn cho lập trình viên mới (quy ước, git, DoD).
- [`pattern-selection-guide.md`](pattern-selection-guide.md) — Chọn pattern nào cho vấn đề nào.
- [`architecture/dependency-rules.md`](architecture/dependency-rules.md) — Quy tắc phụ thuộc giữa module.
- [`architecture/module-overview.md`](architecture/module-overview.md) — Tổng quan từng module.

## Tài liệu theo pattern

Mỗi pattern có `README.md` riêng (sơ đồ PlantUML class + sequence)
đặt cạnh code, ví dụ:
`structural-patterns/src/main/java/com/htv/patterns/structural/adapter/README.md`.

Xem thêm định hướng nền tảng cho Kiro trong `.kiro/steering/`
(`product.md`, `tech.md`, `structure.md`).
